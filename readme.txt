Installed packages (npm)

Core backend packages:
- express
- cors
- dotenv
- mysql2
- jsonwebtoken
- google-auth-library

Also present in dependencies:
- mysql

Install command used:
npm install express mysql2 cors dotenv jsonwebtoken google-auth-library

To install everything from package.json:
npm install

Install openai-agent:
cd back-end
npm install openai
